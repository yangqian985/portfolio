# 阳前的设计作品集

这是一个静态网站，不需要构建工具。首页和两个案例共用同一套样式。

## 修改内容

| 内容 | 文件 |
| --- | --- |
| 首页介绍、精选项目、视觉实验、设计流程、教育背景、技能和联系方式 | `index.html` |
| 白尘美术馆的文字和 PDF 入口 | `项目1.html` |
| 一菓的文字和 PDF 入口 | `项目2.html` |
| 字号、颜色、留白、栏目宽度、手机布局 | `assets/site.css` |
| 导航高亮、视觉实验大图 | `assets/site.js` |
| 设计规范及本次已选方向 | `design.md`、`direction-approved.md` |

图片放在 `images/`，对应的 `img` 标签中修改 `src`、`alt`、`width` 和 `height`。PDF 保存在根目录。新增项目时复制首页 `.project` 链接卡片，修改案例页面及封面路径；同时更新首页的项目计数。

## 本地查看

在仓库根目录运行：

```powershell
py -m http.server 8766 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8766/`。字体由 Google Fonts 加载；页面布局、图片和 PDF 使用仓库文件。

## 发布

如果 Vercel 已连接这个仓库，合并到 Vercel 所配置的生产分支后会触发对应部署。分支或拉取请求的预览是否启用，以该 Vercel 项目的 Git 设置为准。

部署时上传完整仓库内容，至少包含三个 HTML 页面、`assets/`、`images/` 和两个 PDF。保持相对目录结构。
