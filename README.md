# 阳前的设计作品集

网站内容统一在 **[网站内容.json](./网站内容.json)** 修改。Vercel 部署时自动生成首页、项目详情、项目数量和切换链接。

## 最简单：在 GitHub 网页上改

1. 打开 `网站内容.json`，点击右上角铅笔 **Edit this file**。
2. 找到对应的中文字段，只改引号里面的内容。
3. 点击 **Commit changes**。提交到 `master` 后，Vercel 自动构建并发布。
4. 在 Vercel → Deployments 等到 **Ready**，再刷新 [mywk.asia](https://mywk.asia/)。

| 想改什么 | JSON 中的位置 |
| --- | --- |
| 姓名、首页标题、介绍、教育、能力、工具、求职意向 | `个人资料` |
| 联系标题、说明、电话、邮箱、简历 | `联系` |
| 项目名称、封面、说明、详情、PDF | `项目` |
| 独立作品卡片 | `独立作品` |
| 视觉实验图片和名称 | `视觉实验` |
| 品牌构建流程 | `设计流程` |
| 作品集年份 | `年份` |
| 正式域名与搜索引擎链接 | `网站地址` |

保留英文双引号、逗号和方括号。文字内优先用中文引号「」。JSON 最后一项后不加逗号。格式或路径有误会导致构建失败，旧的线上版本继续保留。

## 更新联系方式和简历

- `联系.电话` 为号码数组，两个号码都可展示和点击拨打；例如 `["18143075563", "13606768840"]`。
- `联系.邮箱` 第一项用于首屏邮件按钮和复制邮箱，后续邮箱显示为备用联系方式。
- 上传简历 PDF 到 `files/`，再修改 `联系.简历` 路径。替换同名 PDF 时无需修改页面，文件大小会在构建时自动更新。
- 首页首屏、联系区、案例页导航和案例末尾共用同一份简历与首选邮箱。

## 换图片或 PDF

- 图片用 JPG 或 PNG，上传到 `images/`，再改 JSON 中的 `封面` 或 `图片` 路径。尺寸自动读取。
- 最省事是上传同名文件替换原图，路径不用改。
- PDF 放在根目录，修改项目的 `PDF` 路径。文件大小自动计算。
- GitHub 网页上传单文件有限制，较大的 PDF 可以让 Codex 帮你提交。
- 图片说明也要同步修改，便于无障碍阅读。

## 新增、排序或删除项目

在 `项目` 数组复制一个完整项目对象，修改内容：

- `页面`：独一无二的名称，例如 `项目3.html`。
- `首页名称`、`首页说明`：首页卡片。
- `名称`、`英文副标题`、`概述`、`交付内容`：详情页。
- `设计思路`：填写多组 `标题` 和 `说明`，依次介绍受众、设计问题、策略与应用推导；`方案回顾` 为文字段落数组，记录方案总结和后续完善方向。
- `封面`、`PDF`：已经上传的真实文件路径。

数组顺序就是展示顺序。删除整个对象即可隐藏项目，原图片和 PDF 可以保留。项目计数与详情页自动生成，不用手改 HTML。

当前三个品牌案例均为概念项目。项目设定与策略文案可继续在内容清单中修改；拾月记的问卷数字沿用附件报告。新增网页叙事不会自动改写原有 PDF 手册。

### 添加独立作品

单张海报、标志练习、包装片段和其他单件作品放在 `独立作品` 数组，不需要创建单独详情页。上传图片到 `images/`，然后复制这个对象并填写内容：

```json
{
  "名称": "海报练习",
  "类别": "海报与视觉",
  "年份": "2026",
  "说明": "用一两句话介绍主题或尝试的方向。",
  "图片": "./images/海报练习.jpg",
  "图片说明": "海报画面与主要视觉元素"
}
```

按数组顺序展示。图片等比例完整呈现，点击卡片可放大查看。`独立作品` 可以先留空；填写第一张卡片后，作品网格会自动显示。独立作品与视觉实验现在归在同一个「视觉探索」栏目下，分组单独维护；「精选项目」继续承载完整案例。

### 给项目添加网页展示图

每个项目新增 `展示章节`，网页会自动生成章节导航、图文展示和图片放大功能。可以复制现有章节再修改：

```json
{
  "锚点": "applications",
  "导航名": "应用展示",
  "标题": "从视觉识别，到应用场景。",
  "导语": "用一段话说明这一组图展示的设计重点。",
  "图片": [
    {
      "图片": "./images/新作品.jpg",
      "名称": "包装系列",
      "说明": "解释图中内容，以及希望传达的设计思路。",
      "宽幅": false
    }
  ]
}
```

- `锚点` 使用英文小写、数字和连字符，同一项目中不要重复，也不要用 `overview`、`scope`、`pdf`、`top`、`main`、`lab-lightbox`。
- `导航名` 建议 4 个字以内，最长 6 个字。
- `宽幅` 为 `true` 时图片占一整行，`false` 为双栏；手机均为单栏。
- 不需要图文展示的项目可以省略 `展示章节`，仍会显示概述和 PDF。
- 放大预览支持上一张/下一张、左右方向键和 Escape，关闭后焦点回到原图。

### 网页图片与原始作品

`images/web/` 是从现有 PDF 完整提取并等比例压缩的网页展示图；未裁切、重绘或改动原 PDF。`images/素材来源.json` 记录来源页码。

`images/网页图片.json` 将图片映射到多种尺寸的 WebP 和 JPG 备选。浏览器按屏幕选择尺寸，较大的 JPG 在放大预览时使用。新上传的普通 JPG/PNG 不需要登记这个文件即可显示；需要压缩和多尺寸版本时，可让 Codex 继续处理。

## 本地修改布局

| 内容 | 文件 |
| --- | --- |
| 常改的文字、项目、图片路径 | `网站内容.json` |
| 首页结构 | `templates/index.html` |
| 所有案例共用的详情结构 | `templates/project.html` |
| 字号、颜色、留白、栏目宽度、手机布局 | `assets/site.css` |
| 导航高亮、作品大图 | `assets/site.js` |
| 内容校验与静态页面生成 | `scripts/build.mjs` |
| Vercel 构建与输出目录 | `vercel.json` |
| 图片尺寸与格式映射 | `images/网页图片.json` |

安装 Node.js 22 或更新版本后，在仓库根目录运行（无需安装依赖）：

```powershell
npm run build
py -m http.server 8766 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:8766/`。每次修改 JSON 或模板后重新构建。`dist/` 是实际部署目录，根目录 HTML 是构建同步生成的预览副本，请不要直接编辑。字体由 Google Fonts 加载。

构建还会生成 `sitemap.xml`、`robots.txt`、规范链接及分享预览信息。图片仅复制实际用到的网页版本，原始大图保留在仓库。

## 发布与回退

Vercel 项目 `portfolio-mywk` 连接 GitHub `yangqian985/portfolio`，生产分支是 `master`。布局调整建议先提交新分支，查看 Vercel 预览后再合并。

如需回退，在 Vercel → Deployments 找到之前成功的版本，回退或提升为生产；同时在 GitHub 撤销出错的提交，避免下次构建再次带回问题。

也可以直接告诉 Codex：**“把首页简介改成……并更新网站。”** 或 **“新增一个作品，我提供封面、说明和 PDF。”**
