The project / 项目背景

项目概述

「拾月记」是一项新中式月饼品牌概念设计，也是课程结课作品。以“记录时节、传递团圆”为线索，尝试让中秋礼赠中的文化意味与年轻人的日常分享建立联系。

项目从课程问卷中的品牌名称和消费偏好出发，将方向性反馈转化为月相符号、月白、深蓝与朱红的视觉组合，再延展至单枚月饼、礼盒、手提袋与节令传播，形成从识别到应用的系列提案。

Design approach

设计思路

  1. 从年轻人的节令消费切入

    课程问卷受访者以 18—24 岁学生为主。设计围绕尝鲜、朋友分享和节令礼赠设置应用场景，以单枚包装与组合礼盒回应不同的携带和赠送需要。

  2. 以小样本问卷作为方向依据

    附件报告共记录 26 份有效问卷。「拾月记」在五个候选名称中获得 46.15% 的偏好票，名称与品类的正向契合评价为 84.61%；在口味、包装与价格条件成立时，正向购买意愿为 65.39%。这些结果仅作为课程概念测试的方向性参考。

  3. 把品牌名称转化为视觉记忆

    “拾”关联收集与记录，“月”关联时节与团圆。围绕这一概念，以月相图形建立符号线索，用深蓝、月白与朱红形成主色关系，再通过吉祥物与辅助图形延展亲和感。

  4. 让礼赠体验形成连续的画面

    单枚包装负责风味与识别信息，礼盒和手提袋强化节令主题，贺卡、封套和标签补充赠送时的情感表达。柜台物料与社交媒体画面沿用同一套图形，使不同传播触点能够相互呼应。

01 / 品牌识别

以月为记，建立品牌符号。

从品牌名称和新中式定位出发，以月相图形、深蓝与朱红组织标志、色彩和延展元素。以下为完整规范页面，包含组合关系与使用说明。

02 / 包装应用

从单枚月饼，到节令礼赠。

以概念包装呈现日常尝鲜与中秋礼赠的不同触点。图中规格、文字和场景均为设计提案内容。

03 / 节令传播

把中秋故事带到不同媒介。

以月色与团圆为主题，将同一套视觉语言延展至节令海报和社交媒体版式。

Project review

方案回顾

方案覆盖了品牌基本识别、角色形象、包装与节令传播，并以规范页面梳理组合、色彩和使用方式。课程问卷提供初步的名称与品类方向，视觉提案进一步将这些方向转化为可展示的品牌系统。

下一步可扩大受众范围，通过访谈与包装纸样检验礼赠场景、信息阅读和结构使用。现有问卷不能代表整体市场或真实购买表现；图中的口味、规格、价格与应用场景属于概念提案。
